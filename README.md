# 独立判断型教学 · Independent Reasoning Tutor

一个帮助用户养成“先观察、搜集证据、提出假设并验证，再作出判断”习惯的中文教学 Skill。

当你遇到问题时，AI 很容易一次给出很多可能原因和建议，而你仍不知道应该先查什么、为什么查。这个 Skill 将教学重点放在：帮助你提出有用途的信息需求，选择能区分不同解释的验证步骤，并根据证据修正判断。

它关注学习者能否说明证据、约束和改变主意的条件。适合案例讨论、决策练习和学习复盘，也允许用户随时要求直接讲解。搜集信息应服务于行动；证据足够支持当前行动时，就应作出判断并根据后续反馈修正。

## 项目内容

- [SKILL.md](SKILL.md)：可复用的教学规则与分级提示流程。
- [examples/dialogues.md](examples/dialogues.md)：求职、故障排查、产品、采购与学习场景中，同一提示词在启用前后的模拟对比。
- [EVALUATION.md](EVALUATION.md)：可手动执行的行为验收用例。

这是一份从个人教学实践中抽象出的通用版本。公开项目不包含个人背景、学习进度或原始私人对话。示例均为教学模拟，不代表真实业务成果。

## 快速使用

将整个项目文件夹作为 `independent-reasoning-tutor` 技能目录使用，保持 `SKILL.md` 与 `examples/` 的相对位置不变。支持本地 Skill 的工具可将其放入对应技能目录；具体安装方式以所用工具的说明为准。

在已识别该技能的 Codex 会话中，可尝试：

```text
请使用 $independent-reasoning-tutor，陪我练习如何在信息不完整时作出决策。
我有基础知识，但容易照搬示范。请先给一道短案例，不要提前揭示答案。
```

也可以带着自己的问题开始：

```text
请使用 $independent-reasoning-tutor 复盘我的判断：
我认为应该推迟上线，因为测试还没做完。
请先检查我的依据，不要替我补出我没说过的理由。
```

普通聊天工具也可以读取 `SKILL.md` 后按其教学，但这不等于已安装技能，且效果取决于工具的上下文与指令支持。

## 预期体验

1. 从目标、约束与可用资料出发，提出开放问题。
2. 根据学习者的真实回答反馈，一次聚焦一个薄弱环节。
3. 卡住时逐级提示；进步后减少支持。
4. 用变化后的案例检查迁移，区分独立完成与提示后完成。

完整示例见 [对话示例](examples/dialogues.md)。如果只是想得到答案，可以明确说“请直接讲解”；技能不应强迫你先完成练习。

## 适用范围与局限

适合存在证据、约束和取舍的学习任务，例如产品、设计、工程与日常决策。确定性知识仍应准确讲解，不把事实错误当成观点差异。

Skill 是教学行为约定，不是经过验证的课程体系，也不能保证 AI 的事实准确性或学习效果。真实资料应核实来源；模拟数据必须明确标注。
